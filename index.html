CASE / 06 · ARCHIVED PROJECT

German Music Sync

Одна музыкальная библиотека — Spotify и Яндекс Музыка.

Идея

Создать облачный сервис двусторонней синхронизации плейлистов между Spotify и Яндекс Музыкой. Пользователь продолжал бы слушать музыку в привычных приложениях на телефоне, компьютере, телевизоре и Яндекс Станции — без установки отдельного клиента на каждое устройство.

Что проработали

Архитектуру облачной синхронизации, подключение аккаунтов, сопоставление композиций между каталогами, обработку добавления и удаления треков, защиту от дубликатов и конфликтов.

Почему остановили

Главным препятствием стали ограничения Spotify API, включая требования к доступу для приложений в режиме разработки, а также отсутствие у Яндекс Музыки стабильного публичного API для полноценной интеграции. Неофициальные интерфейсы могут меняться без предупреждения. На такой основе нельзя гарантировать надёжную круглосуточную синхронизацию.

Результат

Удалось проработать рабочую концепцию и техническую схему продукта, но выпускать облачный сервис, который не сможет стабильно поддерживаться из-за внешних ограничений, не стали.

СТАТУСАрхивирован · исходный репозиторий скрыт · публичного релиза нет
CASE / 07 · DESKTOP CONCEPT

AERO7 GRAM

Telegram в стиле Windows 7 Aero.

Идея

Создать отдельный Telegram-клиент с интерфейсом, вдохновлённым Windows 7: стеклянные элементы Aero, привычная оконная рамка и классическая компоновка мессенджера.

Целевая система

Только Windows 7 SP1 — как для x86 (32-bit), так и для x64 (64-bit). Совместимость с более новыми версиями Windows не является основной целью проекта.

Технический подход

Рассматривается нативное приложение на C++ и Qt 5.15 с интеграцией Telegram через TDLib. Подготовлены начальные файлы проекта, каркас окна и документация по сборке для Windows 7.

Текущий статус

На данном этапе есть начальная основа интерфейса и структура приложения. Авторизация Telegram, подключение TDLib, реальные диалоги, отправка сообщений и сохранение сессии пока не готовы. Поэтому проект представлен как прототип и техническая разработка, а не как готовый мессенджер.

ФОКУСLegacy Windows · C++ / Qt · Aero UI · Telegram integration
